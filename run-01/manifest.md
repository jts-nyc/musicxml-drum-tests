# Run 01 manifest

- Date: 2026-11-11
- Machine: macOS 26.6.2, arm64
- MuseScore Studio 4.6.5, driven from its command line (`mscore -o`). Not the current release (4.7.6 at the time of the research).
- Kit: the stock "Drum Kit" (instrument id `drum-kit-5`, 16 drums) from MuseScore's own Rock Band template. Sound set: MS Basic default, untouched.
- The score was generated by `tools/build_fixture.py`, which copies that template's drum part and writes the notes into the score file. It was not entered by hand in the editor. MuseScore then wrote the .mscz, MusicXML, .mxl, MIDI and PDF itself.
- REAPER 7.85 (macOS arm64, build string 7.85.0_19ce87au), evaluation copy. Files were inserted with `tools/reaper_import.lua` (the `InsertMedia` call, each into a new project tab); notes were read back with `MIDI_GetNote`. REAPER's MIDI File Import dialog appeared and was accepted with its defaults. Nothing was edited or saved.
- Not tested in this run: Sibelius, Logic, Dorico, the 23-drum large kit, a Muse Sounds kit, MuseScore 4.2.1 or 4.7.6, live playback inside the MuseScore window.
